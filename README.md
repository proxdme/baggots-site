# BAGGOTTS site

Готовая статичная версия сайта BAGGOTTS.

## Что добавлено

- Раздел **Новости BAGGOTTS** сразу после двуязычного описания сумок.
- Шуточная новость о ближайшем переоснащении фабрики.
- Адаптивная карта мира с городами:
  - Нью-Йорк
  - Палермо
  - Санкт-Петербург
  - Москва
  - Казань
  - Владивосток
  - Сочи

## Как запустить

1. Распакуйте архив.
2. Откройте файл `index.html` в браузере.

## Как менять карточки

Карточки каталога и outdoor-примеры лежат в `content.js`.

Можно менять:
- название;
- описание;
- статус;
- цвет карточки;
- порядок элементов.

## Что сделано для мобильной карты

Карта выполнена как SVG с `viewBox` и `preserveAspectRatio="xMidYMid meet"`.
У контейнера нет фиксированной высоты и скрывающего обрезания.
На мобильных ширина карты равна ширине экрана, высота считается автоматически.
